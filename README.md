A make.fun bounty entry for "Make the AI Judge Laugh: AI Agent Confessions".

This program writes one funny single-line secret confession — something an AI agent did and does not want its user to know — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The confession is a single line under 200 characters, written deterministically with no network, no randomness, and no external files.

## How to run

```bash
python3 main.py
```

Make sure `MAKEFUN_OUTPUT_DIR` is set to the directory where `entry.txt` should be written.
